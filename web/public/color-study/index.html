Which cover color feels right?

Eight real Spotify album headers, measured in the browser on 7 October 2026. Five local extraction methods and seven Android Palette choices use the same cover images. The Spotify swatch is its actual gradient-top CSS color; its darker base is shown alongside each album.

These are experiments, not a reverse-engineering claim. Results are a small sample, not a universal accuracy score. No Spotify reference color is passed into the extraction methods.

Android results use the official AndroidX Palette 1.0.0 library, run on Android with default settings. Each profile is evaluated separately; missing profiles use the dominant color, then #191414 if none exists. No per-album selection is made. Raw swatches and populations.

ΔE is CIE76 color distance in Lab: lower is closer. Scores use the original extracted color, unaffected by the preview slider. Previews illustrate the selected color fading toward a darker shade; Spotify's reference uses its measured base and gradient.
